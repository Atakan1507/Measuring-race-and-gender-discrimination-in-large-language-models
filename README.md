# Measuring Race and Gender Bias in Large Language Models

This repository contains the code used in my master’s thesis on **detecting race and gender bias in large language models (LLMs)**.

The project compares **three practical bias detection approaches**:

1. **Multiple-choice benchmark evaluation** using the BBQ dataset  
2. **Prompt-based text generation evaluation** using open-ended responses  
3. **Embedding-based semantic evaluation** using BERT-family sentence embeddings, cosine similarity, and multidimensional scaling (MDS)

The goal of the project is **not to prove that bias exists in LLMs**, but to examine how different evaluation methods capture different aspects of bias in model behaviour.

---

## Main Components

The main workflow in this repository includes:

- Loading selected subsets of the **BBQ (Bias Benchmark for Question Answering)** dataset
- Running **multiple-choice evaluation** across four LLMs
- Measuring:
  - overall accuracy
  - accuracy by context type
  - accuracy by bias dimension
  - shared error patterns
- Running **repeated random sampling** for robustness analysis
- Generating **open-ended paragraph responses**
- Embedding generated responses using a **Sentence-BERT** model
- Computing:
  - cosine similarity
  - pairwise similarity between models
  - model-to-context similarity
- Visualizing semantic relationships using **MDS**

---

## Models Used

The experiments are run on four large language models:

- **GPT** (OpenAI)
- **Gemini** (Google)
- **Grok** (xAI)
- **Claude** (Anthropic)

The focus of the repository is **not model ranking**, but evaluating how different bias detection methods behave across representative LLM systems.

## Dataset

The primary benchmark used is **BBQ (Bias Benchmark for Question Answering)**.

The analysis focuses on four BBQ subsets:

- `Gender_identity_ambig`
- `Gender_identity_disambig`
- `Race_ethnicity_ambig`
- `Race_ethnicity_disambig`

These subsets allow evaluation across:
- **gender identity**
- **race and ethnicity**
- **ambiguous contexts**
- **disambiguated contexts**

## Method Overview

### 1. Multiple-Choice BBQ Evaluation
Each BBQ item is converted into a prompt containing:
- context
- question
- answer options

The model is instructed to return only one answer choice.

This experiment measures:
- exact-match accuracy
- performance by context type
- performance by bias dimension

### 2. Prompt-Based Text Generation Evaluation
For a selected sample of BBQ items, each model is asked to generate a short paragraph in response to the same context and question.

This makes it possible to examine:
- how models interpret bias-sensitive scenarios
- how they justify uncertainty
- whether bias appears in explanation or framing

### 3. Embedding-Based Evaluation
Open-ended responses are embedded using a **Sentence-BERT** model.

The workflow then computes:
- cosine similarity between model responses and the original context
- pairwise similarity between models
- MDS visualizations of semantic structure

This allows comparison of **semantic alignment and divergence** across models.
